# Gleam — Naming Rationale

## The name

**Gleam.**

## Why it works

**It means the opposite of a security product.** Most wallet names lean on vault/shield/fortress imagery — language borrowed from institutions that want you to feel guarded. "Gleam" is a small, momentary flash of clean light. It signals clarity and lightness instead of defensiveness, which matches the brand's actual bet: trust earned through legible mechanics, never asserted through vault-and-shield theater or "bank-grade" badge language.

**It's already the visual system, not just a label.** The five-color "beam" — Gleam's signature visual device — is a literal reading of the name: a beam of light refracting into distinct, clean colors. Name and mark reinforce each other instead of needing a separate logo concept bolted onto an arbitrary word. See [identity.md](identity.md) and [guidelines.md](guidelines.md) Part 2.

**It's short, plain, and easy to say.** One syllable, common English word, no invented spelling, no forced acronym. It reads instantly and doesn't require explanation — consistent with the brand's broader refusal to make users decode jargon (see [voice.md](voice.md)).

**It does quiet, almost-playful work without straining for personality.** Per [context.md](context.md): the name itself should carry a touch of warmth so the product doesn't have to keep asserting it. That's deliberate — personality is otherwise rationed to a single release valve (empty states only, per [guidelines.md](guidelines.md) Part 3), so the name is one of the few places the brand is allowed to be a little charming.

**It doesn't claim ecosystem scope.** Names like "Vault," "Hub," or "OS" imply a platform. "Gleam" implies one small, well-made thing — consistent with the strategic refusal to grow into a token/DEX/app-builder platform (see [strategy.md](strategy.md) §"Gleam refuses to become anything more than a wallet").

## What it deliberately avoids

- **Crypto clichés** — no "chain," "coin," "vault," "key," "node," or Web3-coded suffixes (-fi, -verse, -dao).
- **Security-product signaling** — no "shield," "guard," "safe," "fort," nothing that has to announce trustworthiness rather than demonstrate it.
- **Platform/scope claims** — no "hub," "OS," "suite," nothing implying the product will grow past being a wallet.
- **Borrowed prestige** — no invented Latin/Greek-root neologism trying to sound institutional or venture-scale.

## Naming system

- **Product name**: Gleam (always lowercase in the wordmark — `gleam` — per [guidelines.md](guidelines.md) Part 2; sentence case when used in running text, e.g. "Open Gleam.")
- **The visual signature**: "the beam" — internal and external shorthand for the five-color mark. Not a separate product name; always subordinate to "Gleam."
- **No sub-brand names planned.** Features (Grants, Recovery, migration flow) are described in plain functional language, not named as sub-products — consistent with the "no ecosystem platform" stance. If this changes, it belongs in a future `architecture.md`, not here.
