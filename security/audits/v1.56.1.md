# Gleam v1.56.1 security audit

## Scope

Diff: `bc052fa..73a6699`, 9 commits. A patch for the Activity feed, plus the MobSF release scan and the Android 10 minimum that merged after v1.56.0.

Surface paths changed:

- `runtime/handlers/activity-reads.ts`: `getActivity` runs the AR and AO gateway queries side by side, and the feed fails only when both fail. A page with one source missing still merges over the local log, which `mergeActivity` keeps entry for entry, so the wallet's own sends and their recorded counterparty and amount are unchanged. `promotePendingActivity` settles only entries the page reports in a block, and checks overdue sends by id, so a page short one source can't mark a send confirmed or failed that it didn't see.
- `apps/mobile/scripts/mobsf-scan.sh` (new), `mobsf-check.mjs` (new), `mobsf-baseline.json` (new), `apps/mobile/.mobsf` (new), `release-app.sh`: the release build is scanned by MobSF before any secret is unlocked. The image is pinned by digest, the container listens on 127.0.0.1 only behind a random API key and is stopped on exit, and the build it scans is unsigned, with `GLEAM_UPLOAD_KEYSTORE` unset for Gradle. A high or warning finding outside the baseline fails the release. `release-app.sh` now requires Docker to be running.
- `apps/mobile/android/variables.gradle`, plugin `build.gradle` files: `minSdk` 26 → 29 (Android 10). This retires the task-hijacking cases that need Android 9 or lower, which is why `.mobsf` skips those two rules.
- `.github/workflows/ci.yml`: a mobsfscan step over the native shells, image pinned by digest, run as the runner's user with no secrets.
- `security/surface.txt`, `.github/CODEOWNERS`: the four MobSF files at tier 5, and owners.
- `apps/extension/package.json`, `apps/mobile/package.json` and the app manifests: the version bump.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`, `pnpm health`.
