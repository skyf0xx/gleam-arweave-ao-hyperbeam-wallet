# Gleam v1.32.1 security audit

## Scope

Diff: `617c4dd..faf0bc6`. One security-surface file changed:

- `apps/mobile/ios/App/App/Info.plist`: `ITSAppUsesNonExemptEncryption` is `false`. All encryption goes through WebCrypto (`crypto.subtle` in `signer/envelope.ts`, `signer/keys.ts`, `vault/encryption.ts`, `vault/passkey.ts`), which WebKit runs on Apple's own crypto libraries. Argon2id is hashing and RSA-PSS is signing, and both are exempt. A search of the built bundle found no cipher implementation.

The other changes:

- `apps/mobile/ios/App/App/Assets.xcassets/`, `apps/mobile/android/app/src/main/res/mipmap-*`, `drawable*/splash.png`: the app icons and launch screens now use the Gleam mark instead of Capacitor's placeholder. They are images only, and the resource XML is unchanged.
- `apps/site/android.html`, `apps/site/ios.html`, `apps/site/vercel.json`: the beta install pages and their redirects. The site's CSP is unchanged, and the pages load no new script origin.
- `apps/mobile/README.md`, `apps/mobile/capacitor.config.mobile.test.ts`: the mobile security model is documented, and a comment now points at it.
- Versions: 1.32.1, with build numbers incremented.

Run:

- `plutil -lint` on `Info.plist`.
- `node scripts/release-gate.mjs`.
- `pnpm mobile:build`, and the `capacitor.config` tests.
