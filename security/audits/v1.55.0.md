# Gleam v1.55.0 security audit

## Scope

Diff: `cf5477b..3e7feec`, 30 commits. Release-pipeline and CI work merged after v1.54.2, two activity fixes, and security docs.

Surface paths changed:

- `core/arweave/graphql.ts`: the activity node schema reads `data.size` as nullable, since arweave.net sends `size: null` for some AO messages. Its one reader already keeps a size only when it is all digits. The GraphQL fallback list swaps `arweave-search.goldsky.com`, which now redirects to arweave.net, for `ar-io.dev`. That host already had a host permission as a first-run gateway, so the manifest only loses Goldsky.
- `apps/mobile/scripts/release-app.sh`: the APK step checks the draft notes for the `<!-- apk -->` marker before it uploads, and writes the APK hash in its place. The hash is `shasum` output, and a missing marker stops the step before any upload.
- `apps/mobile/scripts/verify-bundle.mjs`: when the public download URL doesn't serve the manifest (a draft), it downloads it with `gh` from the fixed repository. The bundle hash is still compared against that manifest, so nothing is trusted that wasn't before.
- `scripts/release-all.mjs`: awaits `writeReadmeBadges`, which became async.
- `package.json` and the app manifests: the version bump.

Read too, outside the surface: `SECURITY.md` (shortened, the Severity rules unchanged in meaning, the `#severity` and `#response` anchors kept), and the `docs/THREAT_MODEL.md` row on lying gateways, which now states the decimals check as the code runs it.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`.

## Findings

| id  | severity | summary | status |
| --- | -------- | ------- | ------ |
| F-1 | low | A `size: null` data item made the whole activity reply fail its schema on every gateway, so the feed and Saved contacts showed a query error. | fixed |
| F-2 | info | The last GraphQL fallback redirected to arweave.net, so an arweave.net outage had no working fallback. | fixed |
| F-3 | info | `ar-io.dev` indexes less history than arweave.net, so a fallback answer can miss older entries. A gateway that drops a transaction is already a listed limitation. | accepted |
| F-4 | info | `verify-bundle.mjs` now hides curl's error output, so a failed public download shows only the `gh` result. | accepted |

## Notes

- THREAT_MODEL said a token's decimals need two other gateways to agree. The check needs every other gateway that answers to agree, and a legacy token with none in its spawn tags takes them from its own `Info`. Docs fix only.
- Known limitations: no change.
