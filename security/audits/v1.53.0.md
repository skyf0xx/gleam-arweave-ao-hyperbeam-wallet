# Gleam v1.53.0 security audit

## Scope

Diff: `15354b6..7286aa2`. The release replaces the paper theme with silica, adds a weather switch that tints silica's sky by the portfolio's change, and adds swipes between the home tabs and an easier pull on the token drawer.

Surface paths changed:

- `packages/core/src/backup/file.ts`: a backup's theme setting may name any theme.
- `packages/runtime/src/handlers/wallet-lifecycle.ts`: the theme setting carries an optional boolean `weather`. The write is guarded by `isThemeSettings` and stores only the two known fields.
- `packages/core/src/models/theme.ts` (read for this audit): `paper` is gone and `silica` is added.
- `packages/app/src/approval/AddTokenScreen.tsx`, `AwaitingDeviceView.tsx`, `ConnectionRequestScreen.tsx`, `packages/app/src/transfer-review/TransferReview.tsx`, `packages/ui/src/components/wallet/AddressDisplay.tsx`, `RecipientCard.tsx`, and the receive and wallet detail screens: class names only, plus the rename of `onGlass` to `onLens`. No rendered value changes.

`useTabSwipe.ts` and `useUndockPull.ts` (exempt) handle touches on the home screen only and touch no data. A panel beside the active one is `inert`. The weather sky shows on home and settings, not on a screen where something is checked or signed. The CSS adds no remote URL.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`, before the backup fix; the backup tests, core tsc and eslint again on it, and CI on the pull request.
