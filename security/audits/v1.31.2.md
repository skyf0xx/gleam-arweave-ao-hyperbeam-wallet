# Gleam v1.31.2 security audit

## Scope

Diff: `v1.31.1..f086191` (#100). Only the mobile release tooling changed. The extension and app code are the same as in v1.31.1.

Surface paths changed:

- `apps/mobile/fastlane/Fastfile`:
  - The App Store Connect key options reach `xcodebuild` once, through `xcargs`. gym appends both `xcargs` and `export_xcargs` to the export, and the duplicate made it exit 64.
  - `skip_docs` stops fastlane rewriting its README, which dirtied the tree between lanes.
  - A new `ios signed_ipa` lane signs without uploading. `beta` runs it, then builds the API key and uploads.
- `apps/mobile/scripts/release-app.sh`:
  - Before any Ruby runs, it fetches `origin/master` with a forced refspec and requires the tag's commit to be on it.
  - It verifies the tag signature against `origin/master`'s `.github/allowed_signers`, written to a temp file, not against the checkout's.
  - It requires the signed tag object's own name to equal the tag.
  - It checks that the interpreter on `bundle`'s shebang is Ruby 3.1 or newer, and that Android has JDK 21.
  - It sets `FASTLANE_SKIP_DOCS=1`.
  - The default entry is now `App Store Connect API`, and the script picks the entry's single `AuthKey_*.p8` attachment. More than one, or none, refuses.
  - The `cleanup` trap is set before the credentials directory is created.
  - It adds an `ios-ipa` target.
- `apps/mobile/Gemfile.lock`: a `CHECKSUMS` section (Bundler 2.6.9). Gem versions are unchanged.
- `apps/mobile/android/gradle/wrapper/gradle-wrapper.properties`: `distributionSha256Sum` for `gradle-8.14.3-all.zip`, matching Gradle's published `.sha256` and a local download.

Run:

- `gitleaks git` on the full history: no leaks.
- `pnpm audit --prod`: 1 low, F-2 of v1.30.0, unchanged.
- shellcheck and `bash -n` on `release-app.sh`.
- The vitest suites for `scripts`, `apps/mobile/scripts` and `security`.
- The Ruby preflight against a fake `bundle` whose shebang is the system Ruby: it refuses.
- The tag-name check against the real signed `v1.31.1` tag.
