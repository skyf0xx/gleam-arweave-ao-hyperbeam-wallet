# Gleam v1.56.0 security audit

## Scope

Diff: `91a8979..bc052fa`, 10 commits. v1.55.0 was tagged but never published: its native projects pointed at a plugin version that wasn't installed, so neither app could build from the tag. This release carries v1.55.0 (audited in `v1.55.0.md`), the browser's full-address view (#426), and the native sync fix.

Surface paths changed:

- `app/screens/browser/src/address-parts.ts` (new): splits an http(s) URL into scheme, subdomain, site, port, path, query and fragment. The site is the registrable domain from `tldts` with private suffixes, or the whole host for an IP or `localhost`. The host comes from `URL`, so it is ASCII punycode, and an internationalised lookalike shows as `xn--…`. Path, query and fragment pass through `readable`, which decodes them and strips control and format characters, so a decoded bidi override can't reorder the text.
- `app/screens/browser/src/address.ts`: `readable` is extracted from `pageTrail` unchanged, so both callers strip the same characters.
- `AddressBar.tsx` (new), `AddressSheet.tsx` (new), `toolbar.tsx` (new), `BrowserView.tsx`: the bar shows the site in bold after its subdomain, which is cut from its start. A 300 ms hold peeks at the full address, and an info button opens a sheet of its parts. Both hide the native page first (`covered`), so the page can't draw over them. Copy writes `URL.href` as loaded. All text renders as React text. Editing starts from the page's URL, and a submit still goes through `resolveInput`, so anything other than http(s) is refused as before.
- `tldts` 7.5.5 (`packages/app/package.json`, `pnpm-lock.yaml`, `scripts/bundle-allowlists.mjs`): pure code with the Public Suffix List bundled. It makes no network calls, has no install scripts, and has one long-standing maintainer. It was already in the lockfile as a dev-only transitive dependency (7.4.12). It is allowlisted for the popup and side panel and listed in SECURITY_PRACTICES.
- Native projects (`Package.swift`, `Package.resolved`, `capacitor.settings.gradle`): point `@capacitor/barcode-scanner` at the installed 3.1.4. OSBarcodeLib moves from 3.0.0 to 3.0.1, pinned by revision, which 3.1.4 requires. SQLCipher and ZIPFoundation keep their pins. Both apps were built from the synced projects (iOS simulator and Android debug).
- `security/surface.txt`, `.github/CODEOWNERS`: the four new browser files at tier 3, and owners.
- `apps/extension/package.json`, `apps/mobile/package.json` and the app manifests: the version bump.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`, `pnpm health`.
