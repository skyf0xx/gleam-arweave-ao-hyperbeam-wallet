# Gleam v1.54.0 security audit

## Scope

Diff: `3035b36..a708a8b`. The release shows cached figures at full strength instead of dimming them, softens the dark theme, makes ignoring a token act at once with a per-row confirm, and adds an update notice for installs that don't update themselves (the Android APK), driven by the site's `latest.json`.

Surface paths changed:

- `packages/runtime/src/handlers/announcements.ts`: `fetchAvailableUpdate` reads `latest.json` from the site with the same credential-free, no-cache GET as the announcements, and returns a version only when the file names this install's shell with a strictly newer `x.y.z`. Anything malformed, a `web` shell or a failed read returns null. The value is a version string only: the notice's link is fixed in the app (the site's download page), so the file can't point anywhere. The site is already trusted for announcements and serves the downloads, so this adds no new party.
- `packages/runtime/src/dispatch/methods.ts`, `packages/runtime/src/create-runtime.ts`, `packages/messaging/src/protocol.ts`: `getAvailableUpdate`, at the `EXTENSION` tier beside `getAnnouncements`. Pages can't call it; it takes no params and opens no approval.
- `packages/app/src/approval/AddTokenScreen.tsx`, `packages/app/src/transfer-review/TransferReview.tsx`: large figures take `dark:font-medium`. Class only; the figures, their text and order are unchanged.
- `packages/app/src/approval/ConnectionRequestScreen.tsx`, `packages/app/src/transfer-review/RequestHeader.tsx`: a site's icon renders at 90% opacity in dark. Class only; the origin and the letter fallback are unchanged.
- `packages/app/src/i18n/messages/main-screen.ts`: the update notice's strings, the ignore hint and the cancel label in all eleven languages; the old ignore confirm and "Ignoring…" strings are gone. No decoded data is translated.
- `apps/mobile/scripts/release-app.sh`: after uploading `gleam.apk`, it runs `scripts/publish-latest.sh`, which runs no npm code: it edits `latest.json` with `node -e` in a temporary worktree off `origin/master`, commits signed, and opens an auto-merging PR. It runs after every signing credential is unset, and master's rules (signed commits, passing CI) still apply to that PR.
- `security/surface-exempt.txt`: `FigurePlaceholder.tsx`, a shimmer that holds a figure's space, exempted with the other wallet display components.

Read for this audit, off the surface:

- `packages/app/src/screens/main-screen/src/MainScreenView.tsx`: ignoring cancels any in-flight balance read, drops the token from the shared balances cache, then calls `removeWatchedToken`, which is unchanged. A failed write refetches, so the row comes back. Send's token picker reads the same cache, so an ignored token leaves it at once too.
- `packages/ui/src/tokens/theme.css`: dark tokens only. Warning, warning fill and caution are unchanged; main text is about 13:1 and faint was raised to keep captions readable on the lighter ground.
- `packages/ui/src/components/wallet/TokenRow.tsx`, `PortfolioChart.tsx`: a figure never read shimmers instead of showing a stand-in 0; a cached one shows at full strength.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`.
