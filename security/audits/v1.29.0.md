## Scope

Diff: `6e8193e..edb14c0` (the v1.28.0 audit commit to master after #77).

Surface paths changed:

- `apps/extension/src/dispatch/methods.ts`, `apps/extension/entrypoints/background/index.ts`, `packages/messaging/src/protocol.ts`: four new background messages, `getDisplaySettings`, `setDisplaySettings`, `getReviewPrompt` and `finishReviewPrompt`, all `EXTENSION` tier. `getTokenPrices` and `getPortfolioHistory` take a display `currency`. Changes off the surface list, read for their effect on what is signed or shown before signing:

- `apps/extension/entrypoints/popup/send/src/SendView.tsx`, `TokenInfoPanel.tsx`: compose and review rework. The amount is still typed in token units and converted with `parseDisplayToAtomic`, capped against the atomic balance. The fiat line is display-only. - `apps/extension/src/handlers/reads.ts`, `packages/core/src/pricing/fx.ts`, `apps/points-api/src/prices.ts`: USD values are converted to the display currency at an FX rate from the Points API, which takes it from CoinGecko or CoinPaprika.

- `apps/extension/src/handlers/announcements.ts`: optional `title`. The `url` allowlist is unchanged.

## Notes

No critical, high or medium finding. What the review checked and found sound:

- **New messages.** All four are `EXTENSION` tier, so only extension pages reach them. None opens a window, reads a key or signs anything.
- **Display settings.** The stored value is validated on write and again on read. A malformed stored value falls back to the defaults, so it never reaches the UI unchecked.
- **Send amount.** The compose rework moved the amount field but kept its pipeline: sanitize, `parseDisplayToAtomic`, then a `BigInt` comparison against the atomic balance. The review screen and the transfer handler are unchanged.
- **Review prompt.** It only reads local state and sets one boolean. It sends nothing over the network.

F-1 was a gap in what the audit covers, not a bug. Both paths are now tier 2 in `security/surface.txt` and `.github/CODEOWNERS`.

F-2 is the purpose of the display-currency feature. The FX rate is cached for an hour and never feeds a signing path.

F-3 comes from the Node polyfill chain the build uses. The wallet does its own signing with WebCrypto and `hash-wasm`, not `elliptic`.

This was one reviewer reading the diff. It was not a full pass over the surface.
