# Gleam v1.56.2 security audit

## Scope

Diff: `bb1869f..7c6c7b1`, 3 commits. Token amounts in the reader's number format, and discovery of token processes spawned without a style tag.

Surface paths changed:

- `app/src/screens/main-screen/src/formatTokenAmount.ts` (new, tier 4): `localizeAmount` regroups an amount the `formatWinston` helpers already formatted. The whole part is grouped as a `BigInt` through `Intl.NumberFormat`, so no digit passes through a float, and the fraction is copied as is after the locale's decimal mark. Text that isn't an amount (`—`, a translated label) comes back unchanged. `formatWinston.ts` is unchanged.
- `app/src/transfer-review/model.ts`, `TransferLines.tsx`, `TransferReview.tsx`, `review-parts.tsx`: `amountText`, `feeText` and `balanceAfterParts` take the reader's locale and pass their existing output through `localizeAmount`. The scaled value, its precision and the fee's round-up are unchanged. An amount of unknown scale still shows its raw units through `groupDigits`, with narrow no-break spaces, the same in every language. Nothing that signs or checks a request reads these strings.
- `app/src/approval/SigningApprovalScreen.tsx`, `AwaitingDeviceView.tsx`: the fee and device-summary amounts go through `localizeAmount`. The five copies of the AR amount line in `SummaryRows` share one local helper.
- `app/src/screens/activity/src/validateSendAmount.ts`: the fee in the over-balance message is localized with `currentLocale()`. The balance comparison itself is unchanged and still runs on atomic `BigInt`s.
- `app/src/i18n/index.tsx`: `currentLocale()`, the language in use for code outside React.
- `security/surface.txt`, `.github/CODEOWNERS`: `formatTokenAmount.ts` at tier 4, and its owner.

Also read, off the surface: `core/ao/asset-scan.ts`'s `classifyAsset`. A `token@1.0` process with no style tag and a one- or two-digit denomination now classifies by shape (denomination 0 and supply 1 is unique, anything else fungible). A style tag still decides when present. Token discovery, Collectibles, activity labels and Add token read this label; a newly classified token takes the same path as a tagged discovered one: listed only with a positive readable balance, hidden by default, never priced, and dropped when it imitates a registry token.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`, `pnpm health`.
