# Gleam v1.53.1 security audit

## Scope

Diff: `7286aa2..81d3f3e`. The release limits the home loading bar to pull-to-refresh, spaces the token picker's cards, speeds up balance and chart reads, and caches collectible images.

Surface paths changed:

- `packages/runtime/src/handlers/reads.ts`: `getPortfolioHistory` and `getPendingTransfers` start their independent reads together. Same hosts, same inputs and same checks on the results. Pending sends are still taken off before a balance reaches the app.

Read for this audit, off the surface:

- `packages/core/src/ao/balance.ts`: hosts that report the same, highest slot for an L1 token are asked together and the first whole number wins. A lower slot is asked only after every higher host fails, and a host with no slot is asked alone and last, so a lagging host can't win by being fast. The host list is unchanged. A balance is display and send-limit data: what is signed is still decoded and checked before signing.
- `packages/ui/src/components/wallet/image-cache.ts`: the cache also matches `/raw/<txid>`. The anchored path still needs a 43-character id and https. Collectibles store raster types only, at most 5 MB. Token logos keep taking any image type, and both are drawn only through `<img>`, which runs no script.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`.
