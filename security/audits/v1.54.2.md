# Gleam v1.54.2 security audit

## Scope

Diff: `5d70867..cf5477b`, 79 commits. Most are docs and release-pipeline work merged after v1.54.1 (OpenSSF documentation, draft releases, SBOMs, changelog gating, README badges), the Android overlay guard, and this release's fixes. Fast-check property tests now cover preview and signing agreement, vault envelope and backup decoding, the page param parsers, and the AO result and GraphQL readers. They found the three robustness fixes below.

Surface paths changed:

- `runtime/handlers/token-reads.ts`: a legacy token's Info reply fills decimals only where the spawn tags carry none and the gateway cross-check agreed. Unconfirmed decimals stay unknown and uncached, whatever one CU says, and agreed decimals are never replaced.
- `core/arweave/graphql.ts`: the activity node schema requires an integer-string `winston`. A reply with anything else is refused, so the next gateway is asked, rather than `BigInt` throwing after the reply was accepted.
- `runtime/handlers/provider-params.ts`: the unknown-`hashAlgorithm` refusal names a non-string value's type instead of calling `String()` on it.
- `messaging/src/page-protocol.ts`: `decodeTaggedBinary` refuses non-number elements before `Uint8Array.from` coerces them. The page script only sends numbers.
- `apps/mobile` overlay guard (`overlay-guard.ts`, `app-platform.ts`, `AndroidManifest.xml`, `OverlayGuardPlugin.java`): while the approval sheet is up, Android 12 and later hide other apps' overlays, and a gesture that starts obscured is dropped. `HIDE_OVERLAY_WINDOWS` is a normal permission, and the API 31 call is SDK-guarded.
- Release pipeline (`release.mjs`, `release-all.mjs`, `release-gate.mjs`, `changelog.mjs`, `pack-release.sh`, `verify-release.sh`, `release-app.sh`): releases stay drafts until the APK step publishes them. `pack-release.sh` still requires the manifest commit to equal the tag commit, the zip hash to match, `gh attestation verify` against the signer workflow and tag, and a local rebuild receipt, so a swapped draft asset fails. Changelog notes are passed as an artifact and never interpolated. Badge values are validated as numbers.
- `vitest.config.ts`, `scripts/test-shards.ts`, `scripts/test-timings.json`: CI shards split by recorded time. The split was checked on the real file list: every file lands in exactly one shard, and a missing or corrupt timings file still gives a full partition.
- `.github/CODEOWNERS`, `security/surface.txt`, `package.json` and the app manifests: owner and surface entries for the shard files, and the version bump.

CI and CodeQL gating (`ci.yml`, `codeql.yml`) was read too. The skip outputs fail open, the parallel `tsc` step fails closed, and `reuse-analysis` fails when master has no analysis to reuse.

Run: `pnpm vitest run` (via `pnpm test:timings`), tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`.
