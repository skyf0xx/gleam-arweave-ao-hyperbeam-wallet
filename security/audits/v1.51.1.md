# Gleam v1.51.1 security audit

## Scope

Diff: `d0808fd..71dc80d`. The release names the paper theme Silica and lays frosted glass over checked addresses on it, softens hovers, marks the active wallet with a green dot, shows which wallet a site connects to, and fixes how a restore merges wallets.

Surface paths changed, by theme:

- **Backup merge.** A restore matches wallets by address, not id, because one key imported on two installs gets a different id on each (`merge.ts`). The active wallet moves to the copy kept when its own is dropped, so the merged data still passes `isValidBackupData`. A copy holding a key beats a hardware copy, and a hardware copy beats a watch copy; only then does the copy changed last win (F-1).
- **Approvals.** The connect approval shows the active wallet's name and address under "Connecting as" (`ConnectionRequestScreen.tsx`, `ApprovalRoot.tsx`). The name is the user's own, not the site's; the site's name still renders through `UntrustedText`. `AddTokenScreen`, `AwaitingDeviceView` and `SigningApprovalScreen` only wrap existing rows in a glass container.
- **Transfer review.** `TransferReview.tsx` splits the from and to rows into `FromParty` and `ToParty` so glass can sit under the recipient. The same values, lookalike diff and warning render.
- **Layout and copy.** Hover classes move from `bg-mist` to `bg-hover` in the browser, lock settings, peers, onboarding, receive and wallet-detail screens, `AddressDisplay` and `RecipientCard`. The paper theme is renamed Silica in every language. The version files carry 1.51.1.

Outside the surface: theme tokens, the portfolio chart, the wallets list, `DESIGN.md`.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`.
