# The security surface: the files where a bug can leak a key, sign
# something the user didn't approve, or let a page past the wallet's
# boundary. The release gate re-audits when any of them change, and
# .github/CODEOWNERS lists exactly these paths.
#
# Format: <tier> <path>. A path ending in / covers the whole directory.
# Tiers, by worst outcome of a bug:
#   1 key material: the key leaks or is lost
#   2 signing: a wrong or unapproved signature
#   3 trust boundary: a page reaches what it shouldn't
#   4 what you see is what you sign: the approval preview lies
#   5 other ways in: extension config, dependencies, CI, the release gate
