How it works

  1. Paste the prompt into your coding agent.

  2. Your agent runs Google's OSV-Scanner to check Gleam for publicly reported security vulnerabilities.

  3. Your agent examines Gleam's code for potential security problems.

  4. You sign an attestation once the scans are complete.

  5. You get rewarded with GLEAM.

Scanning Rewards
  • The first 20 scans earn 0.1% of the total GLEAM points minted yesterday.
  • Scans 21 to 100 earn 0.02%.
  • After that, you must find a vulnerability to earn GLEAM.
  • More severe vulnerabilities earn bigger rewards.
  • Only the first report of each vulnerability earns a reward.
  • Register a Gleam wallet to receive your rewards. The wallet that signs the scan gets the GLEAM.

Bounty Rewards
  • Gleam has a bounty pool that grows daily by 2% of the total GLEAM points minted yesterday.
  • Confirmed vulnerabilities earn a share of the bounty pool:
    Share of the bounty pool by severity
    Critical50%
    High25%
    Medium10%
    Low2%
    Only the first report of each vulnerability qualifies.

Questions

What do I need?
  • A Gleam wallet enrolled in Gleam Points.
  • An AI agent that can run commands on your computer, such as Claude Code, Codex CLI, Gemini CLI or Cursor Agent.

Browser-based AI chats can't run the scan.

Is it safe to run?

Your agent clones Gleam's public code and runs its tests and security scanner. It never needs your seed phrase, private key or real funds.

You can read the full scan instructions before running anything.

What if all 100 paid places are taken?

You can still submit a scan, and its results will appear alongside the others. If your scan finds a confirmed vulnerability, you can still earn GLEAM from the bounty pool.

Paid places reopen with each new release.

What happens if my agent finds a vulnerability?
  • Small fix: your agent opens a pull request with its findings and proposed fix.
  • Serious vulnerability: your agent files a private security advisory with the maintainers.

A maintainer confirms the severity before the bounty is paid to the wallet that signed the attestation.

Does a pass mean Gleam is secure?

A pass means your agent didn't find a vulnerability during its scan.

No single scan can guarantee security, which is why Gleam welcomes independent reviews from different agents and researchers.

What is GLEAM?

GLEAM is the reward token used by Gleam Points and the security bounty programme.
