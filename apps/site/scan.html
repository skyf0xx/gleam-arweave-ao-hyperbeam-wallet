1. Scan a release

Each release awards GLEAM to its first 100 signed scans.

Paste this into your agent

Requirements

You'll need a Gleam wallet enrolled in Gleam Points and a coding agent that can run commands on your computer. Browser chats can't run it.

Scan → Sign → Earn

  1. Your agent clones Gleam's public code and runs its tests.

  2. It runs Google's OSV-Scanner to check for publicly reported vulnerabilities in Gleam's dependencies.

  3. It scans a part of Gleam's code and answers challenges about specific functions, to show it read the code.

  4. After the scan you sign attestation with your Gleam wallet.

Scan rules
  • Each paid scan earns 0.1% of the GLEAM points minted the previous day.
  • Each wallet can scan a specific area once per release.
  • Further scans in the same release earn in 10% increments.
  • Only the first 100 scans are rewarded. Scans after that are only awarded for finding bounties.

2. Report a vulnerability

If your scan finds a vulnerability, your agent will guide you in reporting it and you earn a share of Gleam's growing bounty pool.

Bounty pool
– GLEAM
How to report

Report privately through GitHub's private vulnerability reporting and include your attestation id.

Report privately on GitHub ↗

Maintainers aim to acknowledge reports within a few days. See the security policy for scope and what to include.

Bounty rules
  • The pool grows each day by 2% of the GLEAM points minted the previous day.
  • A confirmed vulnerability is awarded a share of the pool at the time it's confirmed:
    Share of the bounty pool by severity
    Severity Share of pool
    Critical 50%
    High 25%
    Medium 10%
    Low 2%
  • A fix we merge for a confirmed vulnerability adds 1% of the pool.
  • A maintainer sets the severity using the criteria in our security policy.
  • Only the first report of each vulnerability is awarded a share.
  • Small issues may go through a public pull request while high risk goes through a private advisory.
  • Unclaimed balances stays in the pool.

Community scans do not replace a professional audit

A passing scan means only that it found no vulnerabilities. Independent scans from different researchers and models add another layer of scrutiny to Gleam.

We hope to improve Gleam's security by encouraging public scans from as many independent sources as possible.

Questions

Is it safe to run?

Your agent never needs your seed phrase, private key or real funds.

You can read the full scan instructions before running anything.

Can I verify the scans myself?

Yes. Every attestation is signed by the scanner's wallet and published with its signature on the results page. You can check each one without trusting Gleam.

What is GLEAM?

GLEAM is the reward token used by Gleam Points and the security bounty programme.
