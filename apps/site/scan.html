How it works

  1. Paste the prompt into your coding agent.
  2. Your agent runs Google's OSV-Scanner to check Gleam for publicly reported security vulnerabilities.
  3. Your agent examines Gleam's code for potential security problems.
  4. You sign an attestation once the scans are complete.
  5. You get rewarded with GLEAM.

      Scanning Rewards

      • The first 20 scans earn 0.1% of the total GLEAM points minted* yesterday.
      • After that, you must find a vulnerability to earn GLEAM.
      • More severe vulnerabilities earn bigger rewards.
      • Only the first report of each vulnerability earns a reward.
      • Register a Gleam wallet to receive your rewards. The wallet that signs the scan gets the GLEAM.

      * Used metaphorically to aid comprehension.

      Gleam's Bounty Pool

      • Gleam has a bounty pool that grows daily by 2% of the total GLEAM points minted* yesterday.
      • Confirmed vulnerabilities earn a share of the bounty pool:
        • Critical: 50%
        • High: 25%
        • Medium: 10%
        • Low: 2%
        Only the first report of each vulnerability qualifies.
